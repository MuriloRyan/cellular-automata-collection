Ive implemented the following automatas:

- Elementary Cellular Automaton

``` Created by Stephen Wolfram, this is a simple one-dimensional cellular automaton that evolves based on a set of rules. Each cell can be in one of two states (0 or 1), and the next state of each cell is determined by its current state and the states of its two immediate neighbors.```

- Game of Life

``` Created by John Conway, this is a two-dimensional cellular automaton where each cell can be alive (1) or dead (0). The next state of each cell is determined by the number of live neighbors it has. ```
